# Definition of Done - Sprint 11

Le Sprint 11 est termine uniquement si :

- le dossier `packages/core/src/recommendation/` existe
- les 5 fichiers attendus sont presents
- `RecommendationEngine` orchestre la generation
- `RecommendationBuilder` construit une recommandation
- `RecommendationMapper` normalise le resultat
- `RecommendationScore` agrege uniquement des scores deja calcules
- aucun moteur existant n'est modifie
- aucun appel IA n'est ajoute
- aucun appel HTTP n'est ajoute
- aucun acces MongoDB n'est ajoute
- aucune route, controller, scheduler ou notification n'est ajoute
- aucune decision automatique n'est produite
- aucun calcul financier ou technique n'est ajoute
- l'export central de `packages/core` est mis a jour
- le code reste sous controle
- ESLint passe
- Prettier passe
- le smoke import passe
- la documentation Sprint 11 est presente
