# Definition of Done - Sprint 06

Le Sprint 06 est termine uniquement si :

- l'ossature du Trading Core est creee ;
- le TradingPipeline contient les 9 etapes obligatoires ;
- les etapes ne contiennent que des TODO documentes ou de l'orchestration minimale ;
- le PipelineContext transporte les donnees sans logique metier ;
- le TradingCore ne fait qu'orchestrer ;
- aucune IA reelle n'est presente ;
- aucun prompt n'est present ;
- aucun acces MongoDB direct n'est present ;
- aucun import Mongoose n'est present ;
- aucun import Express n'est present ;
- aucun import React n'est present ;
- aucune route n'est creee ;
- aucun controller n'est cree ;
- aucun scheduler n'est cree ;
- aucun calcul metier n'est present ;
- ESLint ne retourne aucune erreur ;
- Prettier ne retourne aucune erreur ;
- le code reste inferieur a environ 500 lignes.
