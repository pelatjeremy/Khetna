# Sprint 17 - Dashboard Skeleton

## Objective

Create a simple TradeAI dashboard skeleton with local mocked data.

## Scope

- Dashboard page in `apps/web/app/page.js`
- Small dashboard components in `apps/web/components`
- Mock state in `apps/web/store`
- Responsive styles in `apps/web/styles/globals.css`

## Acceptance

- Dashboard renders from mocked state
- Components stay small and readable
- No external connection is introduced
- Lint and format pass
