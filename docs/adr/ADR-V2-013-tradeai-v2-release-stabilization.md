# ADR-V2-013 - TradeAI V2.0.0 Release Stabilization

## Status

Accepted

## Context

Tous les sprints TradeAI V2, de V2-01 a V2-12, sont valides.

La release V2.0.0 doit stabiliser le projet sans introduire de nouvelle fonctionnalite.

## Decision

Le sprint V2-13 est un sprint de release uniquement.

Il autorise uniquement :

- documentation
- README
- CHANGELOG
- guides developpeur
- guides utilisateur
- release checklist
- ADR finale
- workflows GitHub si necessaire
- scripts package.json uniquement si necessaire

## Rules

Aucune modification fonctionnelle n'est autorisee.

Sont interdits :

- moteur IA
- API
- dashboard
- scheduler
- notification
- backtesting
- repository
- modele MongoDB
- refactoring massif
- nouvelle architecture

## Consequences

TradeAI V2.0.0 devient publiable comme release stable, documentee et verifiable.

## Out of Scope

- TradeAI V3
- nouvelles fonctionnalites
- changement d'architecture
- optimisation fonctionnelle
