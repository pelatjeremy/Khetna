# Definition of Done - Sprint 04

Le Sprint 04 est termine uniquement si :

- tous les repositories demandes existent ;
- chaque repository expose une API CRUD coherente ;
- les methodes specifiques sont uniquement des methodes de lecture simples ;
- les repositories communiquent correctement avec les modeles Mongoose ;
- les repositories sont exportes proprement ;
- aucun repository ne contient de logique metier ;
- aucun repository ne contient de calcul ;
- aucun repository ne contient de regle de trading ;
- aucun repository ne contient d'appel IA ;
- aucun service n'a ete cree ;
- aucun controller n'a ete cree ;
- aucune route Express n'a ete creee ;
- aucun composant React n'a ete cree ;
- ESLint ne retourne aucune erreur ;
- Prettier ne retourne aucune erreur ;
- le sprint reste inferieur a environ 500 lignes de code.
