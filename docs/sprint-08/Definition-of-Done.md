# Definition of Done - Sprint 08

Le Sprint 08 est termine uniquement si :

- tous les contrats publics des moteurs existent ;
- chaque contrat expose uniquement des signatures de methodes publiques ;
- aucun contrat ne contient d'implementation reelle ;
- aucun contrat ne contient de logique metier ;
- aucun contrat ne contient de calcul ;
- aucun contrat ne contient d'appel externe ;
- aucun contrat ne contient d'acces MongoDB ;
- aucun contrat ne depend d'Express ;
- aucun contrat ne depend de React ;
- aucun moteur existant n'a ete modifie ;
- aucun nouveau moteur n'a ete cree ;
- les exports sont propres ;
- le smoke test d'import reussit ;
- ESLint ne retourne aucune erreur ;
- Prettier ne retourne aucune erreur ;
- le volume reste inferieur a environ 500 lignes.
