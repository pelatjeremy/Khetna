# Definition of Done - Sprint 07

Le Sprint 07 est termine uniquement si :

- le Market Data Engine existe ;
- le Market Data Provider abstrait existe ;
- le Market Snapshot Mapper existe ;
- les exports sont propres ;
- le Trading Core pourra utiliser une interface unique ;
- aucun fournisseur externe n'est integre ;
- aucun appel HTTP n'existe ;
- aucun indicateur technique n'est calcule ;
- aucune logique IA n'est presente ;
- aucun scheduler n'est present ;
- aucun fichier hors perimetre n'est modifie inutilement ;
- ESLint passe ;
- Prettier passe ;
- les imports fonctionnent ;
- le sprint reste inferieur a environ 500 lignes de code.
